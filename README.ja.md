# Community Rule Sources

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

このリポジトリはコミュニティが管理し、KiokuYomi を含む対応リーダーに任意で
インポートできる暗号化ルールコレクションを GitHub Releases で配布しています。

KiokuYomi の公式リポジトリではなく、いずれかのアプリの公式ルール配布元でもありません。
ルールはコミュニティのメンバーが独自に作成・投稿しています。KiokuYomi の開発者は
これらのルールを審査、推奨、保証せず、アプリにも第三者のサイトは組み込まれていません。

このリポジトリは漫画や動画のコンテンツをホストしません。利用する権限のある
コンテンツのみへアクセスし、適用される法律や各サービスの利用規約を遵守してください。

## ソースを探して個別にインポート

**[個別ソース一覧を開く（成人向けソースを除く）](SOURCES.ja.md)**

コレクション全体を追加する必要はありません。一覧を開き、ブラウザーの「ページ内検索」で
名前やルール ID を検索してください。対象の「インポート用リンク」を右クリックまたは
長押ししてアドレスをコピーし、対応リーダーのリモートルール読み込み画面に貼り付けます。
プレビューを確認してから、ご自身の判断でインポートを確定してください。
固定バージョンの `.kyyrule` ファイルをダウンロードして手動でインポートすることもできます。

固定のインポート用リンクは、最新の Release にある対象ソースのパッケージを指します。
クリックするとファイルが直接ダウンロードされる場合があり、アプリへのワンクリック
インストールや、インストール後の自動更新を保証するものではありません。
一覧は公開済みコレクションから自動生成されます。通常ソース一覧にも mature（高年齢層向け）
のソースが含まれるため、全年齢向けの一覧ではありません。

[成人向けソースの別一覧](docs/SOURCES_ADULT.ja.md) は、適用される年齢要件および
法的要件を満たす方が、ご自身の意思で閲覧するためのページです。

## コレクションを手動で追加

KiokuYomi のルールコレクションまたはリモートルール読み込み画面に HTTPS の
コレクション URL を貼り付け、プレビューを確認してから、ご自身の判断で追加を確定してください。

**通常コレクション（成人向けソースを除く）：**

```text
https://github.com/manga-rule-community/sources/releases/latest/download/general.json
```

**完全コレクション（成人向けソースを含む場合があります。適用される年齢要件および法的要件を満たす必要があります）：**

```text
https://github.com/manga-rule-community/sources/releases/latest/download/all.json
```

GitHub raw の代替コレクション URL：

```text
https://raw.githubusercontent.com/manga-rule-community/sources/main/general.json
https://raw.githubusercontent.com/manga-rule-community/sources/main/all.json
```

## 互換性

既存の `kiokuyomi-Community/sources` リポジトリは互換ミラーとして引き続き利用できます。
両リポジトリは同じ公開済み暗号化ルールパッケージを配布しています。
どちらか一方のコレクションを追加すれば十分で、両方を追加する必要はありません。

## 不具合の報告と削除依頼

バージョンやインポートに関する問題、削除依頼は
[リポジトリの Issues](https://github.com/manga-rule-community/sources/issues) に投稿してください。
権利者の方はルール ID、対象となる権利、および確認可能な依頼の根拠を明記してください。
本人確認書類、アカウントの認証情報、非公開の資料、著作物の全文や全編を
公開 Issue にアップロードしないでください。削除は README の変更だけでなく、
正式な上流のリリースと関連する配布先にも反映する必要があります。

アクセスする権限のあるコンテンツにのみ使用してください。ルールの暗号化やリポジトリの分離は、
利用許諾、著作権、プラットフォームのポリシーに関する要件を代替するものではありません。
