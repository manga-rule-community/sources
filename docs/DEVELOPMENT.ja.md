## 配布構成

このリポジトリでは GitHub Pages を有効化せず、独立したソース一覧サイトも作成しません。
Git にはインポート用インデックス、Markdown 形式のソース一覧、配布ツールを保存します。
GitHub Releases には、公開済みの暗号化された `.kyyrule` および `.kyybundle` ファイルを保存します。
漫画や動画のコンテンツ、平文のルール、実行可能な拡張機能、アカウントの認証情報、
Cookie、トークン、復号鍵、署名用の秘密鍵は保存しません。

## インデックスと既存の入口との互換性

コレクションの入口はリリースに合わせて更新されますが、内部の各パッケージ URL は
特定の Release タグに固定されます。これにより、更新中に異なるバージョンが混在することを防ぎます。
**このリポジトリ内**の `sources.json` は、互換性のために用意された `all.json` の別名です。
旧リポジトリの `sources.json` は異なる探索用カタログ形式であり、ここでは書き換えません。
アプリによるサイズ、SHA-256、署名、復号、ロックされたルールの既存の検証も維持されます。

既存の `/v1/rule-catalog`、`/v1/rule-packages/<release>/<id>.kyyrule`、
`/v1/rule-bundles/<release>/<channel>.kyybundle`、`/rules/<id>` の配布経路は変更しません。
旧形式の探索用 `sources.json` と、その Pages/raw ミラーにも影響を与えません。
互換性のためにドメインを維持することは、新しいソース一覧サイトを作成することではありません。
このリポジトリが追加するのは GitHub 上の配布経路です。

## 公開と更新の制約

1. 既存の非公開ルールの審査、署名、暗号化、正式公開の手順は変更しません。
2. 公開済みコレクションと暗号化パッケージのみを読み取ります。非公開のルールソースへのアクセス、復号、再署名は行いません。
3. 完全コレクションと通常コレクションのバージョンが一致し、通常コレクションが成人向け以外の正確な部分集合であることを要求します。すべてのパッケージとバンドルのサイズおよび SHA-256 を検証します。
4. 公開前に上流のコレクションを再取得し、同期中に上流のリリースが切り替わっていないか確認します。
5. ファイルをドラフト Release にアップロードし、GitHub が返す各アセットの SHA-256 を検証してから、公開して `latest` を更新します。
6. コレクションのインデックスと自動生成した一覧を `main` に反映するのは、Release の公開後です。シーケンス番号の巻き戻し、同じ番号での内容変更、公開済みアセットの書き換えを拒否します。
7. GitHub Actions は 6 時間ごとに同期し、手動実行にも対応します。公開前に失敗した場合、以前の Release と入口は変更しません。公開後のインデックス更新に失敗した場合は、直前にコミットされたインデックスを維持します。

同期ツールが検証するのは暗号化・署名の**構造**と整合性のみです。暗号学的な署名検証を
完了したと主張するものではありません。署名検証と復号は、引き続きアプリの既存の
インポート処理が担当します。テスト用の鍵も本番用の鍵も、このリポジトリには保存しません。

## ソース一覧の自動生成

README、ソース一覧、保守ガイドの既定言語は英語です。各ページの上部に
English／简体中文／日本語の切り替えリンクがあります。中国語ページには `.zh-CN.md`、
日本語ページには `.ja.md` の接尾辞を使用します。一覧、README、保守ガイドへのリンクは
選択中の言語を維持します。GitHub の Markdown ファイル間を移動する仕組みで、
JavaScript、ブラウザーの言語判定、GitHub Pages は必要ありません。

英語の一覧は `SOURCES.md`（通常ソース）と `docs/SOURCES_ADULT.md`（成人向けの別一覧）です。
中国語版は `SOURCES.zh-CN.md` と `docs/SOURCES_ADULT.zh-CN.md`、
日本語版は `SOURCES.ja.md` と `docs/SOURCES_ADULT.ja.md` です。
これら 6 ファイルは、`scripts/generate_source_directory.py` がこのリポジトリの
`all.json` と `general.json` から決定的に生成します。項目を手動で追加・削除しないでください。

名前、ルール ID、コンテンツ区分は公開コレクションに基づきます。一覧の生成では
平文ルールの読み取り、パッケージの復号、ソースサイトへの接続を行わず、
ウェブサイトのバックエンド、QR コード、アプリ起動用プロトコルも追加しません。
3 言語でルール ID、並び順、件数、固定のインポート用 URL、固定バージョンの URL を共有します。
翻訳するのは説明文、表の見出し、コンテンツ区分や操作のラベルのみで、元のソース名は維持します。

生成ツールは既存のコレクション形式と固定バージョン URL の検証を再利用します。
バージョン、カタログのシーケンス番号、成人向け以外の部分集合が完全に一致することを要求します。
外部由来の名前はテキストとしてエスケープし、表の破損や Markdown リンク・HTML の
挿入を防ぎます。項目は大文字・小文字を区別しない名前、次にルール ID の順で並べます。
削除されたソースは新しく生成した一覧には残りません。

- 「インポート用リンク」：`https://github.com/manga-rule-community/sources/releases/latest/download/<id>.kyyrule`。
  ユーザーがアプリにコピーするための URL で、取得時点の最新 Release を指します。
  自動インストールやインストール後の自動更新を保証するものではありません。
- 「このバージョンをダウンロード」：コレクション内の既存の固定バージョン URL を使用し、
  一覧のスナップショットに対応するパッケージを取得します。
- `safe`、`teen`、`mature` は通常一覧に含め、`adult` は成人向けの別一覧にのみ掲載します。
  区分は年齢確認ではなく、コンテンツの利用許諾、サイトの稼働状況、アプリによる審査や推奨を証明するものでもありません。

同期ワークフローは Release のアップロード、アセットのハッシュ検証、公開が成功した後に、
`dist` 内のコレクションから一覧を生成します。6 つの一覧と 4 つのメタデータファイルを
まとめてコミットします。一覧は Release のアセットには含めず、公開済みのパッケージや
チェックサムを書き換えません。CI と同期前の確認では `--check` を実行し、
一覧の欠落や古い内容を検出すると、ファイルを書き換えずに失敗します。

## ローカルでの検証

以下のコマンドはリポジトリのルートで実行してください。

Python 3.11 以降と curl が必要です。公開には GitHub CLI も必要です。
サードパーティーの Python 依存パッケージはありません。

```sh
python3 -m unittest discover -s tests -v
python3 scripts/generate_source_directory.py --check
# 生成ツールの変更後は、6 つの Markdown 一覧を再生成してコミットします：
python3 scripts/generate_source_directory.py
python3 scripts/mirror_release.py --output dist/preview
# 任意：準備済みコレクションからプレビューを生成します。追跡中の一覧や公開済み Release は変更しません：
python3 scripts/generate_source_directory.py --catalog-dir dist/preview --output-dir dist/directory-preview
# GitHub Releases への書き込みは、明示的に --publish を指定した場合のみ行います：
python3 scripts/mirror_release.py --output dist/release --publish
```

ミラーツールの実行ごとに空の出力ディレクトリを使用してください。プレビュー後に公開する場合は、
別の空ディレクトリを指定して再実行してください。`dist/` はコミットしません。
公開成功後に `all.json`、`general.json`、`sources.json`、`publication.json` と、
英語・中国語・日本語の 6 つの一覧を Git に同期します。
このリポジトリの `GITHUB_TOKEN` に必要なのは `contents: write` のみです。
アプリ用リポジトリのトークン、Cloudflare の鍵、アプリ署名証明書、
App Store Connect の認証情報は不要です。
